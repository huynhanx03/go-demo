# Go Lab

A digital workbench for advanced Go concepts, focusing on performance optimization, distributed systems, and algorithmic efficiency.

| Experiment | Description |
| :--- | :--- |
| **[Formula Engine](./formula-engine)** | Dynamic formula evaluation engine with dependency graph analysis and cycle detection. |
| **[Promotion File](./promotion-file)** | High-throughput validation service using Bloom Filters for memory-efficient set membership. |
| **[Search Radius](./search-radius)** | Spatial search benchmark comparing in-memory Geohash indexing against disk-based R-Tree solutions. |
